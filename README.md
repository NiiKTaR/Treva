# Treva
Easy connect and control your Smart Home devices online

Also it works best on localhost XAMPP server or simply using https://www.knowhereco.ar/Treva logged on the same Wi-Fi to get the Google Nest and Chromecast/Google TV devices since Google uses proximity verifications for that kind of stuff.

Also it runs on SmartLife project API Key, Secret, UID and username and Magic Home credentials.
